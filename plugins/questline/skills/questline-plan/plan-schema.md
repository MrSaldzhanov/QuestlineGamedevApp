# Questline: формат плана

Данные проекта живут в ветке **`questline`** его git-репозитория (без общей истории с
основной веткой), в папке `plan/`. Вход и установка — `docs/github-app.md`.

| Файл | Кто пишет | Что внутри |
|---|---|---|
| `plan/plan.json` | ИИ (скилл `questline-plan`) | проект, блоки, недели, вехи, задачи |
| `plan/cover.jpg` | ИИ | обложка для фона (необязательно) |
| `plan/board.json` | приложение, все участники | общий статус задач, кто что закрыл, посты, вишлисты |
| `plan/people/<login>.json` | приложение | личный опыт и серии участника |

План и прогресс разделены намеренно: ИИ может пересобрать план сколько угодно раз,
а прогресс привязан к `id` задач и не теряется. **`id` задачи нельзя менять между
версиями плана**, если это та же задача.

## plan.json — `questline.plan/1`

```jsonc
{
  "schema": "questline.plan/1",
  "generatedAt": "2026-10-23",          // дата генерации
  "revision": 1,                        // растёт при каждом перепланировании
  "project": {
    "id": "somnia",                     // латиница, уникален среди проектов
    "name": "Somnia",
    "tagline": "Сюрреалистичная антология снов",
    "emoji": "🌙",
    "accent": "#8B7CF6",                // главный цвет проекта в приложении
    "startDate": "2026-10-26",          // понедельник недели №1
    "weeklyCapacityHours": 22,          // сколько часов в неделю реально есть
    "releaseLabel": "Релиз в Steam",    // как называть финальную точку
    "marketing": {                      // необязательно: включает карточку постов и вишлистов
      "platforms": ["instagram", "reddit"], // instagram | reddit | tiktok | twitter | youtube | bluesky
      "postsPerWeekMin": 1,             // ниже — серия постов рвётся, в четверг приходит напоминание
      "postsPerWeekTarget": 2,
      "wishlistGoal": 3000,
      "wishlistMilestones": [10, 100, 250, 500, 1000, 2000, 3000],
      "hoursPerWeek": 2                 // часы на посты, уже включены в capacityHours недель
    },
    "theme": {                          // необязательно: фон приложения для этого проекта
      "background": ["#2A1E5C", "#161033", "#0A0918"], // 2–4 ТЁМНЫХ цвета сверху вниз
      "glow": "#F59AC0",                // свечение в правом верхнем углу (по умолчанию accent)
      "particles": "stars",             // stars | snow | fireflies | bubbles | petals | none
      "particleColor": "#FFF4E0",
      "image": "cover.jpg",             // файл в папке плана; затемняется и тает к низу экрана
      "imageOpacity": 0.4               // 0..1
    }
  },
  "blocks": [                           // крупные части проекта (сны, системы, звук…)
    {
      "id": "dream-01",
      "name": "Сон №1 «Млечный Путь»",
      "emoji": "🚀",
      "color": "#F6A55C",
      "baselinePercent": 75             // готовность по аудиту до начала плана
    }
  ],
  "milestones": [
    { "id": "demo", "name": "Демо для Steam", "emoji": "🎮", "week": 8,
      "description": "Хаб + Сны 1, 2, 4, 5 со звуком" }
  ],
  "weeks": [
    {
      "index": 1,                        // 1..N, неделя k начинается startDate + 7*(k-1)
      "type": "work",                    // work | polish | buffer
      "theme": "Фаза 0: всё, что сломано",
      "goal": "Сон №1 проходится до конца, все карточки Хаба ведут куда надо",
      "capacityHours": 22
    }
  ],
  "tasks": [
    {
      "id": "d01-pocket-split",          // стабильный id, kebab-case
      "title": "Разнести классы Pocket.cs по файлам",
      "description": "Почему и что именно сделать, 1–3 предложения",
      "block": "dream-01",
      "kind": "agent",                   // agent | review | play | me
      "estimateHours": 1.5,              // часы ТВОЕГО времени за компьютером
      "week": 1,                         // null = бэклог, можно выбрать в любую неделю
      "priority": 1,                     // 1 = критично, 2 = важно, 3 = можно позже
      "deps": [],                        // id задач, которые должны быть сделаны раньше
      "prompt": "Готовый промпт для агента (для kind=agent)",
      "checklist": ["Что проверить, чтобы считать задачу сделанной"],
      "tags": ["bug"],
      "decision": "Вопрос, если результат задачи — выбор (необязательно)"
    }
  ]
}
```

### Типы задач (`kind`)

| kind | Значок | Смысл |
|---|---|---|
| `agent` | 🤖 | делает ИИ-агент; от тебя — поставить задачу и принять результат |
| `review` | 👁 | ты смотришь и решаешь: картинка, концепт, результат агента |
| `play` | 🎮 | ты играешь руками: плейтест, ощущения |
| `me` | ✋ | только ты: аккаунты, деньги, музыка, внешние сервисы |

### Типы недель

* `work` — обычная неделя.
* `polish` — полировка и плейтест: после каждых 3–4 рабочих недель.
* `buffer` — запас на сорванные сроки, ставится перед вехами.

## board.json — `questline.board/1` и people/&lt;login&gt;.json — `questline.person/1`

Приложение хранит у себя объединённый «прогресс» и при синхронизации раскладывает его на
два файла: общий `board.json` (`tasks`, `weeksClosed`, `metrics`) и личный
`people/<login>.json` (`stats`). Слияние правок участников: у задачи побеждает более поздний
`changedAt`, удалённый пост помечается `deleted: true` и не воскресает. Заметка (`note`)
сливается отдельно, по своему `noteAt`, чтобы правка текста не перебила чужую смену статуса.
Задачу в статусе `doing` закрыть или вернуть может только тот, кто её взял (`by`). Серии, достижения и
опыт считаются только по своим отметкам (`by` = свой логин).

Ниже — поля прогресса (в `board.json` те же `tasks`/`weeksClosed`/`metrics`, плюс `schema`, `projectId`, `updatedAt`):

## Прогресс

```jsonc
{
  "schema": "questline.progress/1",
  "projectId": "somnia",
  "updatedAt": "2026-10-30T18:20:00Z",
  "planRevision": 1,
  "tasks": {
    "d01-pocket-split": {
      "status": "done",                  // todo | doing | done | skipped
      "changedAt": "2026-10-27T21:10:00Z", // последняя правка — по ней сливаются участники
      "by": "octocat",                   // логин GitHub того, кто менял
      "doneAt": "2026-10-27T21:10:00Z",
      "week": 1,                         // перенос задачи на другую неделю (если был)
      "note": "Берём Next Fest и IndieCup", // решение (для задач с decision) или заметка
      "noteBy": "octocat",
      "noteAt": "2026-10-28T12:00:00Z"
    }
  },
  "weeksClosed": [1],                     // недели, которые ты закрыл итогом
  "stats": { "xp": 340, "tasksDone": 12, "bestWeekStreak": 3 },
  "metrics": {                            // есть, если в плане задан project.marketing
    "posts": [{ "at": "2026-10-27T18:02:00Z", "platform": "reddit", "by": "octocat" }],
    "wishlists": [{ "date": "2026-11-09", "value": 12, "at": "…", "by": "octocat" }]  // одна запись на день
  }
}
```

Регулярные посты **не** заводятся задачами плана: их отмечают кнопкой в приложении, а
время на них заложено в `capacityHours` (`marketing.hoursPerWeek`). В план идут разовые
маркетинговые задачи: страница магазина, капсулы, тизер, фестивали, пресс-кит, запуск.

ИИ при перепланировании читает `board.json`: что сделано, сколько реально
закрывалось в неделю (фактический темп), что переносилось — и пересобирает
оставшиеся недели, не трогая `id` уже сделанных задач.
