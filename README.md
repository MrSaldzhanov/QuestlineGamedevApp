# 🧭 Questline

Открыл телефон — и сразу знаешь, что делать по проекту. Claude оценивает проект и раскладывает
работу по неделям, а приложение показывает фокус дня, неделю, вехи и прогноз даты релиза.
Есть опыт, уровни, серии, достижения и напоминания. В команде статус задач общий, а опыт у
каждого свой.

## Установка — 4 шага

**📱 На телефоне (Android)**

1. Скачай и поставь **[Questline.apk](https://github.com/MrSaldzhanov/QuestlineGamedevApp/raw/main/Questline.apk)**.
   Если телефон спросит — разреши установку из этого источника.
2. В приложении нажми **«Начать»**:
   * войди через GitHub — код скопируется сам, вставишь его на github.com;
   * нажми **«Установить на репозиторий»** и выбери репозиторий проекта. Если он чужой,
     GitHub отправит владельцу запрос, и проект появится после подтверждения.

**💻 В Claude Code**

3. Установи скилл:
   ```
   /plugin marketplace add MrSaldzhanov/QuestlineGamedevApp
   /plugin install questline@questline
   ```
4. В папке проекта скажи: **«Оцени проект и разбей работу по неделям для Questline»**.
   Claude проверит дизайн-доки и код, оценит остаток и спросит, сколько часов в неделю у тебя
   есть. План появится в приложении.

Дальше по ходу работы говори **«перепланируй»**: Claude посчитает реальный темп команды и
пересоберёт оставшиеся недели, не трогая сделанное.

## Как это устроено

* Данные проекта лежат в ветке `questline` твоего репозитория. Основная ветка не засоряется.
* Приложение получает доступ только к содержимому тех репозиториев, на которые ты его установил.
  Токенов нет: вход по коду через GitHub.
* Обновить скилл: `/plugin marketplace update questline`.
